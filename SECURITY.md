# Security and privacy

This is a static portfolio with no accounts, server-side code, analytics or visitor data store. The contact form opens the visitor's email client; it does not submit to this site.

If you find a vulnerability in the site, avoid posting personal data or exploit details in a public issue. Contact the portfolio owner at `shivasaichavala777@gmail.com` with a short description and reproduction steps. For ordinary content corrections or broken links, open a GitHub issue.
